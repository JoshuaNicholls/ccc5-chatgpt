# CCC5

Working repository for the fifth annual Cursed Conlang Circus (CCC5).

This repository will contain the research corpus, design work, supporting data and scripts, and presentation materials for the language developed for the competition.

## Structure

- `research/` — source register, research log, and research notes.
- `corpus/` — CCC4 submissions and transcript resources used as the comparative corpus.
- `data/` — structured project data and generated datasets.
- `scripts/` — scripts used to process data and support language development.
- `design/` — conlang design documentation and working materials.
- `presentation/` — presentation planning, slides, script, images, and delivery materials.
