# CCC4 comparative corpus

The CCC4 corpus is being reconstructed as a comparative reference set for CCC5.

## Current layer

`ccc4-finalist-corpus.csv` records the 30 entries presented in Agma Schwa's CCC4 judging video, in video order. The video description identifies these as the top 30 highest-voted CCC4 conlangs and supplies timestamps.

This is an index layer, not yet a reconstruction of the individual submissions. Individual URLs, transcripts, linguistic feature extraction and cross-submission analysis remain to be attached.

## Status
- Finalist index: complete
- Individual submission URLs: pending
- Transcripts: pending
- Linguistic feature extraction: pending
- Cross-submission analysis: pending

## Limitation
The judging video presents finalists in random order. The sequence here is therefore presentation order, not ranking.
